# Cloud Networking Labs

A hands-on learning portfolio focused on **Cloud Network Engineering**. This repository documents networking fundamentals, AWS and Azure networking, troubleshooting, and Infrastructure as Code.

> **Learning status:** Labs are added as they are studied and tested. A lab is not marked complete until its steps and verification results have actually been performed.

## Lab Documentation Standard

Each practical lab will include, where applicable:

- Objective and prerequisites
- Network topology and addressing plan
- Step-by-step configuration
- Routing and traffic-flow explanation
- Verification commands or console checks
- Troubleshooting notes and lessons learned
- Cleanup steps and cost considerations

## Cost and Security Guardrails

- Start with theory, diagrams, and local simulations before creating cloud resources.
- Review the current AWS/Azure pricing and free-tier eligibility before deploying anything.
- Do not create billable resources unless the cost is understood and explicitly intended.
- Remove temporary resources after testing and verify the billing dashboard.
- Never commit passwords, access keys, tokens, account IDs, personal payment details, or customer-sensitive information.
- Use placeholder IPs and sanitized screenshots in public documentation.
